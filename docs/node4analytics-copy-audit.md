# node4analytics Landing Page Copy Audit

Date: 2026-04-28

Scope: Copy recommendations only. No frontend code, layout, or design changes are included.

Context: The company name is now `node4analytics`. Use `n4a` where the shorter form improves readability, especially in body copy and tight navigation labels.

## Naming Guidance

Use `node4analytics` in formal brand positions:

- Navigation logo
- Footer logo
- Copyright
- Page metadata when the brand is the subject
- First formal brand mention where clarity matters

Use `n4a` in body copy where the full name interrupts the sentence:

- Hero subheading
- Workflow descriptions
- Value prop cards
- Contact copy
- Navigation labels such as `Why n4a`

Avoid `Node4analytics` unless the brand intentionally uses title case. Based on the current naming direction, lowercase `node4analytics` should be treated as the formal brand.

## Copy Audit Summary

Overall tone: clear, credible, and much stronger than generic AI finance copy. The best lines name the analyst's actual workflow pain: context switching, traceability, source confidence, and moving from data to report.

Biggest opportunities, ranked by impact:

1. Replace most body-copy uses of `Node4analytics` with `n4a`.
2. Remove generic productivity language like `Improve efficiency. Boost productivity.`
3. Tighten AI claims so they emphasize traceability, drafting, and analyst judgment rather than broad reliability claims.
4. Standardize brand casing across navigation, footer, metadata, and body copy.

Preserve:

- `Your research lives in six tools. It shouldn't.`
- `Thirty minutes. No slides. No pitch.`
- The workflow sequence from filings to research base to signal to canvas to spreadsheet to report.
